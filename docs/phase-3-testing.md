# Phase 3 — manual test checklist

Scope: epic #74 and issues #51, #48, #49, #53, #59, #52 and #61.

## Load the updated build

Use `build/chrome` for Chrome or `build/firefox` for Firefox. If you already load an unpacked build, copy the new package contents into that same build folder, reload the extension, and refresh your Workday tabs. Keep the same extension identity to retain local saved plans. For Firefox, use the manifest in the Firefox package.

Start with two saved plans that differ by at least one section. Include a lecture and a lab/tutorial, two or three overlapping meetings, an online course, and alternating-week classes if available. Save any working changes before testing JSON backup. Test destructive replacement in a separate browser profile or with disposable plans after checking your exported backup.

## What to test and what should change

| Test | Steps | What you should see |
| --- | --- | --- |
| Schedule overview | Open the Schedule tab, then expand **Schedule overview**. Load a different plan and add/remove a section. | Scheduled hours, gaps, campus days, days off, busiest dated day, earliest start/latest end and conflict counts update. Each metric has an explanation. No overall score is shown. |
| Dates and online teaching | Compare an ordinary weekly class with a biweekly class, online teaching and separate terms. | Biweekly time is averaged over actual dates. Online classes do not add campus days. Different terms are counted across their teaching ranges, rather than stacked into one week. Partial teaching weeks are included and explained. Missing/uncertain meetings are excluded and reported. |
| Compare two plans | In the main Workday Schedule tab, choose **Compare saved plans**, then select two plans. Change either selector and switch Week 1/2. | Two timetables appear side by side, with independent horizontal scrolling when needed. Added/removed/changed sections are listed; **Δ** marks affected blocks. Summary statistics are available for both. The week controls update both plans. Merely opening, switching or closing comparison preserves saved data and your working schedule. |
| Preferred plan | Click **Set as Preferred** beneath the second plan. Close and reopen the browser popup. | Exactly that saved plan is preferred and becomes the popup default. Comparison is absent from the popup. |
| Automatic section alternatives | Open the relevant Workday course-section results, load your plan, and click **Section alternatives** on its course card. | The extension automatically checks matching section links/IDs already available on the authorized page. **Find alternatives on this page** retries discovery. If data is absent or unavailable, the message explains how to use a pasted link. Discovery does not navigate or enroll you. |
| Pasted-link swap preview | Paste another UBC Workday **Section** link and click **Preview pasted section**. Try a section with several meeting patterns or different dates. | The complete proposed timetable appears with conflicts, unknown times and pairing/date warnings. Other components remain present. Different or cross-listed codes and component types produce warnings. Nothing changes until **Apply section swap**. |
| Apply and Undo | Apply one replacement, then open the Schedule tab and click **Undo section swap**. Repeat but edit the working schedule before Undo. | Apply replaces just the chosen component and updates statistics, conflicts and unsaved status. Undo restores the pre-swap draft. If later edits would be overwritten, Undo refuses and explains why. Saved snapshots are unchanged until you save. Workday enrollment never changes. |
| Safe Workday links | On a loaded saved plan, open a course's section-link button. Test a missing/stale link and a pasted link from another tenant or website. | A valid section opens in a new tab. The original tab stays open. Unsupported links are refused or shown as unavailable. Expired/missing section data gives sign-in/current-link guidance. No registration action occurs. |
| JSON export | Choose **Backup / Restore** from Schedule, or the backup button in Settings. Export all plans and then one selected plan. Open the JSON as text. | Versioned files include the requested plans, names, preferred status, course/instructor/room details, course colors, hover preference and saved time format. Unsaved working edits are not included. Tokens, credentials and Google Calendar account/sync data are absent. |
| Merge restore | Import a backup, inspect **Merge**, confirm it, and repeat with a changed plan using an existing name/ID. | Preview appears before writes. Identical copies are skipped. Conflicting records receive separate IDs/names; existing plans and preferred status are preserved. Existing display preferences win. More than 10 resulting plans is refused. |
| Replace restore | Select **Replace** after importing a disposable backup. Try confirming without checking the confirmation box; then check it and confirm. | No data changes before explicit confirmation. Confirmed replacement restores the file's saved plans and preference defaults/settings together. Working courses and account data remain present. Reload Workday to apply restored display preferences. |
| Invalid backup | Try malformed JSON, an unsupported version, invalid settings, or a file with an untrusted section URL. | A readable error appears and existing data stays intact. The preview does not offer a valid import for rejected content. |
| PNG and PDF | Choose **Download PNG / PDF** in the main Schedule tab; also try the popup downloads. Export portrait and landscape. Search/filter the course list first, and include weekends, long names and overlapping classes. | Files contain the full schedule, independent of search and the visible scroll area. The grid uses numbered course references when space is tight; subsequent details contain full codes, sections, titles, instructors, rooms, dates and times. PNG includes all pages vertically; PDF has A4 pages in the chosen orientation. Conflict details and unknown meetings are included. No internal Workday links/account IDs are printed. |
| Three-way conflicts | Add three simultaneous sections. Expand **Conflicts and transitions** near the top of the timetable. | Concurrent blocks occupy separate lanes rather than covering each other. **!** and dashed borders identify clashes. The list gives exact overlap times, section names and all shared dates. **Show [section]** returns to the matching course card in the main panel. |
| Transitions and uncertainty | Compare back-to-back/under-15-minute transitions, opposite teaching weeks, and an unanchored biweekly meeting. | Close transitions are described separately from confirmed clashes. Meetings on different dates do not clash. Uncertain recurrence is reported as unknown, rather than asserted to be a clash or conflict-free. |
| Keyboard and popup | Use Tab/Enter/Space on overview/conflict disclosures, timetable blocks, comparison selectors and modal controls. Close dialogs with Escape. Open the popup in a narrow window. | Focus is visible; descriptions identify sections without relying on color. Dialog focus stays inside and returns to its opener on close. Popup controls fit the window, while wide timetables scroll horizontally. |
| Existing save behavior | Load a saved plan, edit, cancel a Quick Save confirmation, then Quick Save or Save As New. Clear the draft, reopen saved plans and download an ICS file. | Existing save confirmations, status chips and plan ownership still work. Cancelling preserves the draft/snapshot. Saving becomes green only after persistence succeeds. Clearing affects the draft; saved plans remain available. |

## Verification already completed

- 73 automated tests passed, including the existing Phase 0–2 suite and new date/statistics, conflict-lane, comparison, swap, backup validation, trusted-link, redirect/error and export tests.
- Chrome and Firefox packages built successfully.
- Isolated Chromium checks with synthetic Workday data passed: read-only comparison, preferred plan, authorized-page alternative discovery, swap preview/apply/Undo, PNG/PDF downloads in both orientations, JSON backup, malformed-file rejection, replacement confirmation and a 420px popup. No browser script errors occurred; fixture Workday requests used GET only.
- Exported PDF pages were rendered and visually inspected. These PDFs contain image pages; the details are visually readable but are not selectable PDF text.

Real UBC-account discovery, actual section navigation/sign-in behavior, Firefox runtime behavior, and a backup round-trip between separate real installations remain manual checks. Automated fixtures cannot establish those outcomes. Do not close the epic as fully verified until those checks and merge are complete.

The current extension has no personal commitment-block model or user-selectable theme setting. There is no such data to export in this baseline; the backup includes all currently supported non-sensitive preferences, rather than copying arbitrary storage keys.
