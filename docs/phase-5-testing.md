# Phase 5 manual checks

Reload the existing unpacked extension from `build/chrome` and refresh Workday. Use version **3.0.15**. Firefox packages use `build/firefox`.

| Feature | Try it | Expected result |
| --- | --- | --- |
| Ranked suggestions | Open **Schedule → Find schedule suggestions**. Add one required group per course. Paste one current Workday **Section** link per option line, or place the links for a Workday-confirmed lecture/lab combination together on one line. Try a Friday option and a later starting option. | **Find suggestions** checks the links and shows up to five distinct conflict-free schedules with a timetable and a breakdown for the enabled priorities. Move a priority up or down and search again to see the ranking change. Earlier finishes and Later starts are alternatives. A Friday option can still appear. |
| Hard constraints | Leave an existing class or personal block in the draft and give the optimizer an overlapping option and a non-overlapping option. Include an unavailable Workday link. | Unrelated draft courses and personal blocks stay fixed. Suggestions respect dated meetings, alternating weeks and skipped dates. Unavailable or uncertain options are skipped. A group with no available options or a search with no valid combinations gets a message. |
| Apply and undo | Select a suggestion and choose **Apply to draft**. Try **Undo** and **Redo** before saving. | The draft changes with one history step. Saved copies update only through the regular save controls. |
| Share a draft | Choose **Import / Export → Share schedule**. Review a draft that contains courses, notes and a personal block. Create a share link, then opt in to personal blocks and create another. | Preview shows course, meeting, instructor and room information. Notes, saved names, settings, Workday IDs and authenticated links are excluded. The personal block appears only after opt-in. Copy the link or download its share file. |
| Open and compare | Open the link in a signed-in Workday browser with the extension installed. You can also paste the link or choose a downloaded file under **Open shared schedule**. | Preview appears before any save. **Add to saved schedules** creates a new copy with a unique name, leaving existing plans and the current draft intact. Use **Compare saved plans** to compare it. |
| Link and file limits | Share a schedule with enough distinct meeting data to exceed the link limit. Try an altered or incomplete link. | Above 4,096 characters, **Download share file** replaces the link. Invalid input shows an error. Files and decoded payloads are capped at 512 KB. |

The optimizer reads the Workday Section links supplied by the user. Check current seats and confirm allowed lecture/lab pairings in Workday before adding those options. Each group is required and contains options for one course and term. A search accepts up to 12 groups and 60 links and stops at 30,000 option checks. When limited, it shows the best results found so far. Preference ranking compares actual Friday/campus dates, the earliest start, the latest finish and average gap minutes per class day. Personal blocks constrain the search and are excluded from those measurements.

Share links hold compressed schedule data in the URL fragment. They need no schedule upload and have no expiry or revocation. Open links from an already signed-in session. If a sign-in redirect interrupts the link, paste the original link into **Open shared schedule**. Anyone with the link or file can read its preview. Review personal block text before including it.
